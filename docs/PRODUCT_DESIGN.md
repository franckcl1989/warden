# Warden 0.1.0 产品设计

状态：`APPROVED_BASELINE`

## 1. 产品使用者

0.1.0 提供三个内置角色，权限定义见 `SECURITY.md`：

- 管理员：配置用户、设备和凭据，查看运行状态与审计，并可执行全部原始业务操作；
- 运维员：查看全部监控并执行被授权的原始业务操作；
- 观察员：只读查看设备、监控、事件、当前问题和任务；

角色是平台安全支撑，不扩展硬件业务范围。

## 2. 信息架构

| 路由 | 页面 | 主要目的 |
| --- | --- | --- |
| `/login` | 登录 | 本地账号认证 |
| `/overview` | 总览 | 查看所有设备当前可达性、健康、当前问题和任务概况 |
| `/devices` | 设备 | 查看和筛选已接入设备 |
| `/devices/new` | 添加设备 | 配置管理连接、测试并启用采集 |
| `/devices/:id` | 设备详情 | 查看该设备全部监控、事件、能力和原始操作入口 |
| `/alerts` | 当前问题 | 查看设备明确当前状态/告警、离线和数据过期形成的当前及已恢复问题；设备日志另在事件页查看 |
| `/operations` | 操作任务 | 查看人工硬件操作的状态、过程和结果 |
| `/files` | 文件 | 管理固件、ISO、配置备份和支持日志 |
| `/audit` | 审计 | 查看用户操作和安全事件 |
| `/users` | 用户与角色 | 管理本地用户和固定内置角色分配 |
| `/system` | 系统状态 | 只读查看 API、Worker、数据库、文件存储和协议接收器状态 |

不提供机房、机柜、资产台账、工单、通知、采集参数编辑或通用监控规则页面。采集周期、Trap/Syslog 监听等工程参数只由部署配置管理。

## 3. 总览

总览回答三个问题：哪些设备不可达、哪些设备不健康、哪些人工操作尚未结束。

### 3.1 顶部统计

- 设备总数；
- 在线、离线、未知数量；
- 健康、警告、严重、未知数量；
- 当前严重问题数量；
- 运行中和结果待核验的操作任务数量。

### 3.2 设备类型摘要

按服务器、群晖 NAS、核心交换机、接入交换机展示在线/离线和健康分布。卡片只跳转到带筛选条件的设备列表，不执行设备操作。

### 3.3 需要关注

按“离线 > 严重 > 警告 > 数据过期”排序，展示设备名称、类型/型号、问题摘要、首次发生时间、最近采集时间和详情入口。

### 3.4 最近操作

展示最近人工操作的动作、设备、发起人、状态、开始时间和结果摘要。点击进入任务详情。

## 4. 设备列表与接入

### 4.1 设备列表字段

- 用户定义的设备名称；
- 设备类别；
- 厂商/管理卡与型号；
- 管理地址；
- 可达性；
- 综合健康；
- 当前问题数；
- 最近成功采集时间；
- 启用状态。

列表支持按名称、管理地址、设备类别、厂商/型号、可达性、健康和启用状态筛选。0.1.0 不提供批量危险操作。

### 4.2 添加设备

仅管理员可添加设备，步骤固定为：

1. 选择设备类别、厂商/管理卡和型号；
2. 输入设备名称和管理地址；
3. 选择协议参数并录入凭据；
4. 执行连接测试和能力发现；
5. 查看发现到的厂商、型号、固件、序列号和能力清单；
6. 保存并启用采集。

添加表单不包含机房、机柜、U 位等字段。序列号、FRU、端口、磁盘等由设备发现，不要求人工重复录入。

连接测试分别显示：网络可达、TLS/协议握手、认证、身份识别、能力发现。任一步失败都给出可操作的错误原因。

连接失败时允许保存为“未就绪”，但不能启用采集或执行硬件操作；只有连接测试成功后才能启用。

### 4.3 编辑与停用

- 修改管理地址、协议参数或凭据后必须重新连接测试；
- 停用设备会停止采集并禁止新操作，但保留历史数据、文件和审计；
- 0.1.0 不提供从界面永久删除设备，避免破坏追踪证据。

## 5. 设备详情

### 5.1 通用头部

所有设备显示名称、类别、厂商/型号、管理地址、序列号、固件版本、可达性、综合健康、数据时间、启用状态和能力发现结果。

操作按钮由 `device_capabilities` 的固有支持状态和 API 动态计算的当前可用性共同生成：

- 支持状态 `supported`：适配器、设备和固件明确支持；满足权限且当前 `available` 时可执行；
- 支持状态 `unsupported`：不可点击并显示设备/固件证据；
- 支持状态 `not_configured`：不可点击并指向缺失协议、凭据、许可或部署配置；
- 当前可用性 `temporarily_unavailable`：支持状态不变，但因离线、维护模式或互斥任务暂不可执行，并显示原因。

界面不得显示一个无真实适配路径的“占位成功”按钮。

### 5.2 服务器详情

页签：

- 概览：综合健康、资产信息、温度摘要、当前故障；
- 温度与内存：CPU/内存/进风口/主板温度，ECC 和内存条状态；
- 存储：磁盘、S.M.A.R.T、预测故障、RAID；
- 电源与风扇：电源在位/状态/负载/电压，风扇转速；
- 事件：SEL 和部件故障；
- 操作：`SRV-ACT-01` 至 `SRV-ACT-07`。

### 5.3 群晖 NAS 详情

页签：

- 概览：系统健康、温度、风扇、电源、UPS、网络；
- 磁盘：S.M.A.R.T、坏扇区、损毁/降级；
- 存储：存储池/RAID、重建进度、卷和共享文件夹使用率；
- 任务与日志：快照/备份任务状态、系统日志；
- 操作：`NAS-ACT-01` 至 `NAS-ACT-06`。

### 5.4 核心交换机详情

页签：

- 概览：CPU/内存、电源、风扇、温度和当前异常；
- 端口：管理/运行状态、流量、CRC、错误和丢包；
- 光模块：收发光功率、温度、电压和电流；
- 二层与日志：环路、广播风暴、STP、端口震荡、重启和认证失败；
- 操作：`CORE-ACT-01` 至 `CORE-ACT-07`。

### 5.5 接入交换机详情

页签：

- 概览：CPU/内存、电源、风扇、温度和当前异常；
- 端口：状态、流量和错误；
- PoE：端口供电、单端口功耗和总功耗；
- 光模块：上联端口光功率；
- 日志与操作：`ACCESS-ACT-01` 至 `ACCESS-ACT-06`。

## 6. 状态语义

状态必须分维度显示，不能合并成一个模糊颜色。

### 6.1 可达性

- `unknown`：尚无成功或失败证据；
- `online`：最近采集成功；
- `offline`：连续 3 次基础连接失败。

一次失败只产生采集错误，不立即判离线；离线后连续 2 次成功才恢复在线。

### 6.2 综合健康

- `unknown`：尚未得到可解释的健康数据；
- `healthy`：设备明确报告健康，或该适配器认证过的完整健康证据集均为健康；
- `warning`：存在降级、阈值警告或非致命部件异常；
- `critical`：存在故障、失效、预测故障或厂商严重事件。

优先级为 `critical > warning > healthy > unknown`。离线属于可达性，不覆盖最后一次健康值；界面同时展示“离线”和“最后已知健康”。

“没有收到异常”不能单独推导 `healthy`。关键采集缺失、部分失败或适配器没有完整健康映射时保持 `unknown`，同时展示成功取得的局部指标。

### 6.3 数据新鲜度

- `unknown`：该受支持指标尚无一次成功观测；
- `fresh`：数据时间不超过采集周期的 2 倍；
- `stale`：超过 2 倍但不超过 3 倍；
- `expired`：超过 3 倍。

设备不支持某指标属于能力支持状态，不属于时间新鲜度；不支持时不伪造指标点。

### 6.4 当前问题

当前问题只由设备明确上报的当前健康/故障/告警状态、连接离线和数据过期产生。设备日志/Trap/Syslog 是时间点历史，不自动升级为当前问题。CPU、内存、容量、错误计数、温度和功率等数值仍按原始需求展示，但没有设备明确告警状态时不由平台发明阈值。生命周期只有：

- `active`：问题仍存在；
- `resolved`：恢复条件已满足。

0.1.0 不提供人工确认、派单或关闭告警。相同设备、组件、规则使用稳定去重键，避免每次采集生成重复告警。

## 7. 人工操作交互

### 7.1 持久化任务流程

除 KVM/DSM/Web/SSH/Telnet 远程连接外，所有原始功能项都使用持久化任务：

1. 用户在设备详情选择原始需求允许的任务动作；
2. 平台检查角色、设备状态、能力状态和互斥任务；
3. 页面展示目标设备、动作、参数、预期影响和不可逆风险；
4. 高风险操作要求最近 5 分钟内完成密码复验并输入设备名称确认；
5. 服务端签发 60 秒有效、绑定用户/设备/动作/参数/设备版本的确认令牌；
6. 用户提交后立即生成持久化任务；
7. 页面跳转任务详情，通过 SSE 更新进度；
8. 任务结束后展示设备返回、回读验证、产物文件和审计编号。

重试高风险操作必须创建新任务并重新确认，不能直接重放旧任务。

### 7.2 风险等级

- 低风险：资产/固件查询、日志采集、配置备份、光模块诊断、快照/备份状态查看；
- 中风险：KVM/DSM/Web/SSH/Telnet 连接、S.M.A.R.T 检测；
- 高风险：重启/关机/强制重启、BMC 冷复位、端口开关、PoE 通断电、配置恢复、固件升级、虚拟介质挂载。

所有操作均审计；高风险操作必须设备名确认。

### 7.3 远程连接

- 远程连接使用 `/launches` 一次性票据，不进入副作用任务队列，也不要求输入设备名；但仍需权限、能力/当前可用性检查、限流和完整会话审计；
- KVM：平台优先创建厂商 HTML5 KVM 会话并生成受审计启动描述符；无法安全创建会话时打开明确 KVM 入口并允许厂商再次认证，不在 URL 中注入密码；
- DSM 和设备 Web 管理：平台在新标签页打开受控管理地址，不注入密码；
- SSH/Telnet：平台创建短期终端票据，浏览器通过 WebSocket 连接；Telnet 默认禁用；
- 终端记录用户、设备、协议、开始/结束时间和断开原因，不默认记录按键和屏幕内容，避免采集密码。

## 8. 文件工作流

文件类型严格限定为原始需求所需：

- `firmware`：固件升级输入；
- `virtual_media`：服务器 ISO/USB 镜像；
- `support_bundle`：TSR、SEL、NAS 技术支持报告、交换机诊断包；
- `config_backup`：交换机配置备份；
- `operation_log`：操作产生的日志附件。

上传后计算 SHA-256、记录大小/MIME/上传者并执行类型与容量检查。固件、ISO、配置备份和支持日志均视为敏感文件；观察员只能查看授权范围内的元数据，不可下载内容。文件不能由 Web 服务器直接按路径公开，只能通过授权下载接口获取。

## 9. 页面级验收

- 任一监控条目能从设备详情找到明确展示位置；
- 任一人工操作按钮能显示来源需求编号和当前能力状态；
- 设备离线、指标不支持、凭据错误和数据过期在界面上含义不同；
- 危险操作无法绕过预览、确认和权限校验；
- 操作完成后任务页、设备详情和审计记录语义一致；
- 页面不出现机房/机柜、工单、通知、通用资产等超范围入口。
