## 1. 快照用途

本文件是原页面的本地只读语义快照，解决后续开发者或 AI agent 无法访问飞书时误读需求的问题。它不取代飞书：飞书原文优先于本快照；`PROJECT_SPEC.md` 中的 51 个编号是工程追踪标识；`contracts/capabilities.json` 是派生白名单。

任何人发现飞书与本文件不一致时必须停止相关实现，先更新本文件、`PROJECT_SPEC.md`、机器契约、追踪矩阵和决策记录。不得只改代码或只改其中一份清单。

## 2. 原始表格逐项快照

### 2.1 服务器

型号/管理卡：戴尔（iDRAC）、浪潮（iBMC）、超聚变（xFusion iBMC）、联想（XCC）、华为（iBMC）。

监控项：

1. 整机综合健康状态（Health/告警灯）
2. CPU/内存/进风口/主板温度
3. 内存 ECC 错误、内存条故障
4. 硬盘状态 + S.M.A.R.T + RAID 降级/失效 + 预故障（Predictive Failure）
5. 电源：双电源在位/故障/负载、电压
6. 风扇转速及过低告警
7. 机箱入侵、面板告警灯
8. SEL 系统事件日志（部件故障）

功能项：

1. 远程管理卡复位（iDRAC/iBMC/XCC 冷复位）
2. 远程开机/关机/强制重启（Power On/Off/Cycle）
3. 远程 KVM 控制台连接（远程连接）
4. 一键采集日志（TSR 技术支持报告/SEL/系统日志打包）
5. 远程挂载虚拟介质（ISO/USB）
6. 固件版本查询与升级
7. 资产信息查询（序列号/FRU 部件）

### 2.2 NAS 群晖

型号：DS224+、DS225+。

监控项：

1. 磁盘 S.M.A.R.T 健康、坏扇区、磁盘损毁/降级
2. 存储池/RAID 状态（降级、重建中）
3. 系统温度、风扇转速、电源状态
4. 存储空间使用率（卷/共享文件夹）
5. UPS 联动状态
6. 系统日志、网络连通性

功能项：

1. 远程重启/关机
2. 远程连接（DSM Web 管理界面）
3. 一键采集日志（日志中心/技术支持报告）
4. 磁盘健康检测（S.M.A.R.T 快速/完整检测）
5. 快照/备份任务状态查看
6. 固件升级、SNMP 告警配置

### 2.3 核心交换机

型号：`s5732-h48xum2cc`、`S5731S-S48P4X-A`。

监控项：

1. CPU/内存利用率
2. 端口 up/down 状态、流量、CRC 错误包、丢包
3. 光模块：收发光功率、温度、电压、电流
4. 双电源在位/故障、风扇转速、整机温度
5. 环路检测、广播风暴、STP 状态
6. 关键日志（端口震荡、设备重启、认证失败）

功能项：

1. 远程重启交换机
2. 端口远程开启/关闭（shutdown/undo shutdown）
3. 远程连接（SSH/Telnet/Web 网管）
4. 一键采集日志（display diagnostic-information）
5. 配置备份/恢复
6. 光模块诊断信息查询
7. 固件升级

### 2.4 接入交换机

型号：`S5735-L48P4S-A1`。

监控项：

1. CPU/内存利用率
2. 端口状态、流量、错误包
3. PoE 供电状态、单端口功耗、总功耗告警
4. 电源/风扇/温度
5. 上联口光模块功率

功能项：

1. 远程重启
2. 端口开启/关闭
3. PoE 端口远程通断电（重启下联终端/摄像头/AP）
4. 远程连接（SSH/Web）
5. 一键采集日志、配置备份/恢复
6. 固件升级

## 4. 不允许擅自解释的地方

- “强制重启（Power Cycle）”在统一契约中只对应一个动作 `power.cycle`，不得再拆出一个语义重复的 `power.force_restart`。
- “共享文件夹使用率”必须产出百分比语义，不能用单独的已用字节数冒充使用率。
- “PoE 总功耗告警”必须有总功耗、功率预算/阈值依据和告警状态，不能只展示瓦数后声称已覆盖告警。
- 虚拟介质卸载是 `SRV-ACT-05` 挂载生命周期的安全收尾动作，不是独立新增业务；只能在同一来源编号下实现和展示。
- 任何功能项的多动作拆分都必须仍绑定原始编号，并在 `contracts/operations.json` 明确参数、前置条件和成功判定。
